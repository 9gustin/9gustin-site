## El problema

La API de Notion devuelve el contenido de una página como una lista de bloques en JSON. Para mostrarla en un sitio hay que traducir cada tipo de bloque a HTML a mano.

## La solución

`@9gustin/react-notion-render` toma esos bloques y los convierte en componentes de React. Sirve para usar Notion como CMS de un blog o para publicar una página de Notion como sitio.

## Cómo está hecho

- Escrita en TypeScript y publicada en npm.
- Permite reemplazar los componentes que vienen incluidos, darles estilos propios y armar una tabla de contenidos.
- Es mi proyecto open source con más uso: 151 estrellas en GitHub.
